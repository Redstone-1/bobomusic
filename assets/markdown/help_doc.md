# 啵啵音乐使用帮助

> 无需登录、无广告。歌单、喜欢、歌词、播放队列和下载都保存在本机；卸载 App 或清除应用数据会一并丢失，请留意。

## 一、先认识三个页面

底部有三个入口：

- **歌单**：本地音乐、我喜欢的音乐、自定义歌单、播放队列。
- **广场**：热门歌手、收藏合集、在线搜索。
- **设置**：主题、检查更新、定时关闭、缓存清理、帮助 / 声明 / 鸣谢。

点击歌曲会直接开始播放，不会自动弹出全屏播放页；需要看封面、歌词或切歌时，点击底部迷你播放条进入播放卡片。

## 二、歌单与播放队列

### 1. 本地音乐

- **Android 手机**：进入「本地音乐」后点右上角刷新按钮，扫描手机中的音频文件。首次使用需要授予音频/存储权限。
- **iPhone / iPad、电脑版**：点右上角文件夹按钮，从文件选择器导入音频；也可以点空状态里的「从文件导入」。导入的文件会保存到 App 内。
- 扫描会跳过系统目录和 App 自己的下载目录，避免出现重复条目。
- 重新扫描不会丢失喜欢状态和已匹配的歌词；手机里删掉的文件，会从本地列表中移除。

### 2. 我喜欢的音乐

- 喜欢是**歌曲全局属性**：在播放卡点歌名旁的心形，或在「我喜欢的音乐」列表行尾点心形，所有歌单里的同一首歌都会同步。
- 「我喜欢的音乐」按喜欢时间倒序排列，最新喜欢的在最前。
- 列表头部的刷新按钮会重新读取本机记录。

### 3. 自定义歌单

- 点歌单页右上角 `+` 新建，最多 20 个。
- 歌单名不能为空、最长 20 个字符、不能以数字开头；重名会被拒绝。
- 歌单行右侧 `⋮` 可以重命名或删除。删除歌单只删除歌单，**不会删除歌曲本身**。
- 在歌曲行右侧 `⋮` 选择「加入歌单」，可以把当前歌曲加入任意自定义歌单；已经在歌单里的歌曲不会重复加入。

### 4. 播放队列

播放队列独立于歌单，用来临时安排接下来要听的歌：

- 歌曲菜单里的「下一首播放」：插到当前歌曲后面，优先播放。
- 歌曲菜单里的「加入待播放」：追加到队列末尾。
- 队列允许同一首歌重复出现；队列会跨启动保留。
- 歌单页下方的「播放队列」区可以查看队列。点击队列中的歌曲会从该曲开始播放，并把这一条从队列取出；行尾 `⋮` 可以「从队列移除」。
- 播完一首或手动点下一首时，会优先播放队列里的第一首；队列为空时再按当前播放模式和会话列表切歌。
- 通过合集详情里的「加入待播放」批量加入时，会**替换当前队列**，请留意。

## 三、广场与搜索

### 1. 热门歌手

- 广场顶部展示热门歌手，不需要联网。
- 点歌手头像进入歌手歌单；点「更多」进入完整歌手列表。
- 歌手歌单里的歌曲行统一使用歌手封面，便于识别。

### 2. 收藏合集

- 收藏的 B 站合集显示在广场下方，两列网格。
- 点合集进入详情，可以逐首播放，或把合集歌曲加入播放队列。
- 合集名与歌单名不能重复；如果已有同名歌单/合集，会提示收藏失败。

### 3. 搜索与音源选择

打开广场顶部的搜索框进入搜索页。**输入框下方可以选择音源：B 站 / 酷我，每次进入默认 B 站**。切换音源会按当前关键词重新搜索。

- **B 站**：
  - 单曲结果显示为歌曲行，点击即播。
  - 多 P（分 P）视频显示为「多P 歌单」行，点行进入合集详情；点右侧书签按钮可以收藏为合集。
  - 支持 B 站视频、多 P 视频与合集。
- **酷我**：
  - 返回单曲结果，点击即播；歌曲行会显示「酷我」音源标签。
  - 酷我结果不包含多 P 视频和合集。
  - 如果当前音源搜不到，换另一个音源或换关键词再试。

搜索结果中的歌曲行右侧 `⋮` 可以：加入歌单、下一首播放、加入待播放、下载（本地歌曲不显示下载）。

> 点播、加入歌单、收藏合集或下载后，歌曲会自动保存到本机，方便下次使用。

## 四、播放器

### 1. 迷你播放条

- 有当前歌曲时，迷你播放条悬浮在底部 Dock 上方；没有播放内容时自动隐藏。
- 显示封面、歌名、歌手、进度线和播放/暂停按钮。
- 点击迷你条进入全屏播放卡；在歌单详情、搜索、合集等页面也会显示迷你条。

### 2. 播放卡片

- 中间是旋转黑胶，内嵌当前歌曲封面；暂停时停止旋转。
- 顶部显示「正在播放」；右上角 `…` 可以打开定时关闭、去 B 站看视频。
- 歌名下方显示音源标签（B 站 / 酷我 / 本地）和歌手。
- 进度条支持点按与拖动定位；时间按真实音频时长显示。
- 控制区依次为：播放模式、上一首、播放/暂停、下一首、当前播放队列。
- 底部动作：歌词视图切换、下载、稍后听；喜欢请点歌名旁的心形。
- 右上角 `…` 里的「去 B 站看视频」仅对 B 站歌曲显示：优先打开 B 站 App，未安装时打开网页。
- 关闭播放卡不会停止播放，迷你条会继续显示。

### 3. 四种播放模式

点击控制区最左侧按钮循环切换：

| 模式 | 行为 |
| --- | --- |
| 单曲循环 | 播完当前歌曲自动重播；手动上一首/下一首仍会切歌 |
| 列表循环 | 播完自动下一首，队尾回到队首 |
| 随机播放 | 随机选一首，尽量避开当前歌曲 |
| 顺序播放 | 播完最后一首后停止 |

播放模式会保存，下次启动继续使用。

### 4. 断点续播

下次打开 App 会恢复上次播放的歌曲、进度和播放模式，并以暂停状态显示；点播放即可继续。播放队列也会跨启动保留。

### 5. 通知栏与耳机键（Android 手机）

- Android 手机播放时会在通知栏/锁屏显示封面、歌名、播放/暂停、上一首/下一首和进度。
- 耳机线控或蓝牙按键可以播放、暂停和切歌。
- Android 13 及以上首次启动会请求通知权限；如果拒绝，通知栏控制不会显示。
- 部分手机会限制后台播放，需要把啵啵音乐加入电池白名单。

### 6. 定时关闭

设置页和播放卡右上角 `…` 都可以打开定时关闭：

- 15 / 30 / 60 / 90 分钟后停止。
- 「播完当前曲」：当前歌曲播放结束后停止，不再自动切下一首。
- 「关闭定时」：取消当前定时任务。
- 定时关闭只在本次运行中有效，重新打开 App 后不会保留。

## 五、歌词

- 打开播放卡时会自动加载歌词；同一首歌只要匹配过一次，下次会直接显示。
- 切到歌词视图后，当前行会随播放进度高亮并自动滚动；有翻译时会合并显示。
- 歌词视图顶部：
  - 搜索按钮：按歌名/歌手搜索歌词。
  - 校准按钮（有歌词时显示）：歌词提前/延后 0.5 秒或 2 秒、重置校准、搜索替换、删除歌词。
- 校准设置会保存，下次播放同一首歌仍生效。
- 没有找到歌词时，可以手动搜索；如果歌词库没有收录，可能无法匹配到合适的歌词。

## 六、本地音乐与下载

### 1. Android 手机扫描

在「本地音乐」点刷新按钮，按提示授予权限后扫描。扫描会读取标题、歌手和时长；标题缺失时使用文件名，歌手缺失时显示「未知歌手」。个别文件读取失败不会影响其他歌曲。

### 2. 从文件导入

在「本地音乐」点右上角文件夹按钮，使用文件选择器选择一个或多个音频文件。文件会保存到 App 内后出现在本地音乐列表。

### 3. 下载

- 入口：播放卡底部「下载」，或歌曲行右侧 `⋮` →「下载」。
- Android 手机：保存到系统下载目录的 `Download/啵啵音乐`，需要存储/所有文件访问权限。
- iPhone / iPad：保存后通过系统分享面板导出到你想保存的位置。
- 电脑版：保存到系统下载目录下的 `啵啵音乐`。
- 下载会优先使用已经缓存的内容，不重复消耗流量；已经下载过的歌曲会提示「已下载」。
- 下载成功后，即使从搜索或广场进入，也会优先播放本地文件，断网也能听。
- 下载的歌曲请仅作个人学习使用，并遵守版权方要求。

### 4. 播放缓存

- 在线播放时会边听边缓存已经完整播放过的内容，重复播放更快。
- 设置页「清理音频缓存」会删除播放缓存，**不会删除你下载的歌曲**。
- 缓存会自动管理，不需要手动维护。

## 七、设置

- **主题模式**：浅色 / 深色。
- **主题色**：8 种颜色，选择后立即生效并保存。
- **检查更新**：检查是否有新版本；有更新时会显示更新说明，并可以打开下载页面。
- **定时关闭**：见「播放器 · 定时关闭」。
- **清理音频缓存**：显示当前缓存占用，确认后清理。
- **帮助 / 声明 / 鸣谢**：查看本文、使用声明和开源致谢。
- **当前版本**：显示当前安装的版本号。

> 搜索音源在搜索页输入框下方选择，可以随时切换。

## 八、常见问题

**搜索没有结果或提示失败？**

1. 检查网络连接。
2. 换一个关键词，或切换 B 站/酷我音源再试。
3. 如果当前音源暂时搜不到，稍后重试或换另一个音源。

**歌曲点播失败 / 提示原视频已丢失？**

- 有些视频可能已经失效或暂时无法播放，换一首或换音源搜索。
- 已经下载到本机的歌曲，断网时也可以播放。
- 长时间暂停后如果无法继续，重新点播即可。

**下载失败？**

- Android 手机需要授予存储/所有文件访问权限，可以到系统设置中检查。
- iPhone / iPad 保存后需要在分享面板中选择保存位置。
- 网络中断或空间不足也会导致失败。

**歌词没有或对不上？**

- 在线歌词库可能没有收录，也可能匹配到其他版本。
- 在歌词视图点搜索按钮手动搜索，预览后应用。
- 时间轴有偏差时用校准按钮提前/延后，校准会保存。

**没有通知栏控制？**

- 确认 Android 13 及以上已经授予通知权限。
- 确认手机没有限制后台运行或电池优化。
- 通知栏控制仅在 Android 手机提供。

**卸载或清除数据后歌单没了？**

- 啵啵音乐没有账号和云同步，所有内容只保存在本机。卸载 App、清除应用数据或更换设备都会丢失歌单、喜欢和歌词。
- 已经下载到系统下载目录的音频文件不会随 App 卸载自动删除，但 App 内的歌单记录会丢失。

**播放队列会保留吗？**

- 会跨启动保留。播放队列中的歌曲被播放或手动移除后才会消失。
- 合集详情的「加入待播放」会替换当前队列。

**搜索结果里有片段、伴奏或翻唱？**

- 在线搜索结果可能包含试听片段、伴奏、翻唱等版本，请根据歌名和歌手选择需要的版本。

## 九、使用须知

- 无需账号；暂不提供云同步、备份和歌单导入导出，换设备前请留意。
- 在线搜索、播放和歌词需要网络；网络不稳定或内容暂时不可用时可能失败，可以换关键词、换音源或稍后重试。
- 合集支持逐首播放和批量加入队列，不保证自动连播。
- 歌词可能缺失或匹配到其他版本，可以手动搜索和校准。
- 互联网音乐版权归原平台及版权方所有；本 App 仅供交流学习，请勿传播或用于谋利。
