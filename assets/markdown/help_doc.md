# 啵啵音乐使用帮助

> 无需登录、无广告。歌单、喜欢、歌词、播放队列和下载记录都保存在本机；卸载 App 或清除应用数据会一并丢失。

## 一、页面入口

- **歌单**：本地音乐、我喜欢的音乐、自定义歌单、最近播放；右上角进入下载管理或新建歌单。
- **广场**：五源榜单与在线搜索。
- **设置**：主题、下载管理、定时关闭、缓存清理、检查更新、帮助 / 声明 / 鸣谢。

点击歌曲直接播放，不会自动弹出全屏页；点底部迷你播放条进入播放卡。

## 二、歌单与队列

### 1. 本地音乐

- **Android**：点右上角刷新按钮，授予音频 / 存储权限后扫描。扫描舱显示实时文件与进度，可随时取消；读取失败的文件在结束后集中列出。
- **iPhone / iPad、电脑版**：点右上角文件夹按钮使用文件导入，从文件选择器选取音频，文件会保存到 App 内。
- 扫描会跳过系统目录和 App 自己的下载目录；重新扫描不会丢失喜欢状态和已匹配歌词，手机里删除的文件会从列表移除。

### 2. 我喜欢的音乐

- 喜欢是**歌曲全局属性**：在播放卡动作行点心形，或在列表行首点心形，所有歌单里的同一首歌都会同步。
- 「我喜欢的音乐」按喜欢时间倒序排列。

### 3. 自定义歌单

- 点歌单页右上角 `+` 新建，最多 20 个。
- 歌单名 1~20 个字符、不能以数字开头、不能重名。
- 行尾 `⋮` 可以重命名或删除；删除歌单**不会删除歌曲本身**。
- 歌曲行 `⋮` →「加入歌单」；已在歌单里的歌曲不会重复加入。

### 4. 最近播放与播放队列

- 「最近播放」显示最近 10 首；标题右侧「清空」只清除记录，不影响歌单、喜欢和下载。
- 「下一首播放」插到当前歌曲之后，「加入待播放」追加到队列末尾；队列允许重复，并跨启动保留。
- 查看和调整队列：播放卡控制区的「播放队列」按钮；行尾 `⋮` 可以设为下一首或移除。
- 播完一首或手动点下一首时，优先播放队列里的第一首；合集详情的「全部加入待播放」是**追加**到队尾，不会清空现有队列。

## 三、广场与搜索

### 1. 榜单

- 广场顶部是搜索入口，下方为五张榜单：酷我热歌榜、酷我飙升榜、网易云热歌榜、网易云飙升榜、千千新歌榜。
- 点歌曲直接播放；单张榜单加载失败可点「重试」，不影响其它榜单。

### 2. 搜索

- 搜索框下方可切换音源：**B 站 / 酷我 / 网易 / QQ / 千千**，默认 B 站；切换后按当前关键词重新搜索。
- 输入框聚焦且无关键词时显示搜索历史，最多 10 条，可单条删除或清空。
- B 站结果包含单曲和多 P / 合集行；其它音源以单曲为主，搜不到时换音源或换关键词。
- 歌曲行 `⋮`：加入歌单、下一首播放、加入待播放、下载（本地歌曲不显示下载）。
- 合集行：点行进入详情；书签按钮收藏为歌单；`⋮` 可「全部加入待播放」「全部下载」。

## 四、播放

### 1. 迷你条与播放卡

- 迷你条显示封面、歌名、单句歌词和上一曲 / 播放 / 下一曲；点击进入播放卡。
- 播放卡主体是歌词视图；下方依次为歌名与音源标签、动作行、进度条、控制区。
- 动作行：喜欢、下载、稍后（插到待播放队首）、倍速；倍速支持 0.5×~2.0× 七档，选择后保存。
- 控制区：播放模式、上一首、播放 / 暂停、下一首、播放队列。
- 右上角 `…`：定时关闭；B 站歌曲另有「去 B 站看视频」。关闭播放卡不会停止播放。

### 2. 播放模式

| 模式 | 行为 |
| --- | --- |
| 单曲循环 | 播完当前歌曲自动重播；手动上一首 / 下一首仍会切歌 |
| 列表循环 | 播完自动下一首，队尾回到队首 |
| 随机播放 | 随机选一首，尽量避开当前歌曲 |
| 顺序播放 | 播完最后一首后停止 |

播放模式会保存，下次启动继续使用。

### 3. 断点续播、通知栏与定时关闭

- 下次打开 App 会恢复上次播放的歌曲、进度、播放模式和播放队列，并以暂停状态显示；点播放即可继续。
- **当前版本不提供通知栏、锁屏和耳机键 / 蓝牙播放控制**，请在 App 内或播放卡中操作。
- 定时关闭：15 / 30 / 60 / 90 分钟、「播完当前曲」或「关闭定时」，只在本次运行中有效。

## 五、歌词

- 打开播放卡会自动加载歌词；同一首歌匹配过一次后，下次直接显示。
- 歌词随播放进度高亮并自动滚动，有翻译时合并显示；迷你条会显示当前一句。
- 歌词视图顶部：搜索按钮按歌名 / 歌手搜索；校准按钮可提前 / 延后 0.5 秒或 2 秒、重置校准、搜索替换、删除歌词。
- 校准设置会保存，下次播放同一首歌仍生效。
- 歌词会依次尝试多个在线歌词库，仍可能缺失或匹配到其它版本。

## 六、下载与缓存

- **入口**：播放卡「下载」，或歌曲行 `⋮` →「下载」；本地歌曲不显示下载。
- **Android**：保存到系统下载目录的 `Download/啵啵音乐`，需要存储 / 所有文件访问权限。
- **iPhone / iPad**：保存后通过系统分享面板导出到目标位置；**电脑版**保存到系统下载目录下的 `啵啵音乐`。
- 已下载歌曲会优先播放本地文件，断网也能听；下载时会优先复用播放缓存，不重复消耗流量。
- 设置页「下载管理」分为「已下载」和「下载中」：失败任务可重试，删除下载会移除本地文件但不影响歌单中的引用。
- 在线播放会边听边缓存；设置页「清理音频缓存」只删除播放缓存，**不会删除已下载歌曲**。

## 七、设置

- **浅色 / 深色**：点设置页右上角按钮切换，立即生效并保存。
- **主题色**：10 种颜色，选择后立即生效并保存。
- **下载管理**：查看已下载与下载中的任务。
- **定时关闭**：见「播放 · 定时关闭」。
- **清理音频缓存**：显示当前缓存占用，确认后清理。
- **检查更新**：读取线上发布页的版本信息；有更新时可查看说明并打开下载页。
- **帮助 / 声明 / 鸣谢**：查看本文、使用声明和开源致谢；当前版本显示在「检查更新」副标题中。

## 八、常见问题

**搜索没有结果或提示失败？** 检查网络，换关键词，或切换音源（B 站 / 酷我 / 网易 / QQ / 千千）再试。

**点播失败 / 提示原视频已丢失？** 在线内容可能失效或暂时不可用，换一首或换音源；已下载的歌曲断网也能播放。

**下载失败？** Android 需要授予存储 / 所有文件访问权限；iOS 需要在分享面板中选择保存位置；网络中断或空间不足也会失败。可在「下载管理」重试。

**歌词没有或对不上？** 歌词库可能未收录或匹配到其它版本；在歌词视图手动搜索，并用校准提前 / 延后。

**没有通知栏控制？** 当前版本不提供通知栏、锁屏和耳机键控制，请回到 App 内操作。

**卸载或清除数据后歌单没了？** 啵啵音乐没有账号和云同步，歌单、喜欢、歌词、队列和下载记录只保存在本机。已下载到系统下载目录的文件通常不会随 App 卸载删除，但 App 内记录会丢失。

**播放队列会保留吗？** 会跨启动保留；歌曲被播放、移除或清空后才消失。「全部加入待播放」是追加到队尾。

## 九、使用须知

- 无需账号；暂无云同步、备份和歌单导入导出，换设备前请留意。
- 在线搜索、播放和歌词需要网络；内容不可用时换关键词、换音源或稍后重试。
- 在线音乐版权归原平台及版权方所有；本 App 仅供交流学习，请勿传播或用于谋利。
