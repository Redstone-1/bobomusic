# origin_sdk · 模块地图

> 接口清单与参数见 `项目文档.md` 第 8 章；本文补**鉴权状态机**与**易踩坑**。基线 0aac7bb，2026-10-24 核对。

## 一句话模型

`BiliClient implements OriginService`：每个公开方法开头 `await init()`（幂等）自举鉴权材料，然后 WBI 签名发请求；鉴权材料 = WBI 密钥 + spi 指纹（buvid3/buvid4）+ bili_ticket + b_nut，四样各自带缓存。

## 引用关系

```
origin_sdk/service.dart（全局单例，UI/内核直接 import）
    ├─ var service = BiliClient()      ← 播放取流（source.dart）、下载、搜索
    └─ var lyricService = LyricClient() ← 歌词/封面（card.dart、lyric_search/preview）

BiliClient [bili/client.dart]
    ├─ Dio 实例：拦截器统一注入 UA/Referer/cookie；onResponse 里校验 code/v_voucher
    ├─ init()：SharedPreferences 缓存（bili_* 前缀，版本号 _cacheVersionValue="4"）
    │    ├─ getBNut()：裸请求 www.bilibili.com 抓 Set-Cookie（b_nut/buvid3），内存缓存仅 1s
    │    └─ 未过期 → 直接还原 signData/spiData/ticket
    │       过期 → Future.wait([nav(拿WBI密钥), finger/spi, GenWebTicket]) 并写回缓存
    ├─ search / searchDetail / searchSeason / searchSuggest
    └─ getMusicUrl(id)：fnval=16 → dash.audio 按 bandwidth 降序取[0] → {url, headers:{Referer}}

WBI 签名 [bili/sign.dart]：encWbi(params, imgKey, subKey)
    mixinKeyEncTab 混淆 → 32 位 mixinKey → 参数+wts 排序 → MD5(query+mixinKey) = w_rid
票据 [bili/ticket.dart]：GenWebTicket，HMAC-SHA256，key_id=ec02
ID 编码 [bili/utils.dart]：BiliId，"aid_bvid[_cid]"，playurl 必须有 cid
```

## 鉴权状态机要点

- `init()` 缓存有效期判定 `inDays > 1`（接近 2 天，与注释「一天」不符，12.9）。
- 缓存版本号机制：改签名/票据算法时递增 `_cacheVersionValue` 即可让全量用户重刷材料。
- **playurl 不带 cookie**（拦截器特判 `/x/player/wbi/playurl` 路径），其它接口带 `buvid3/buvid4/bili_ticket/b_nut`。
- 响应含 `v_voucher` ⇒ 触发风控，拦截器直接 `BotToast` + 抛 DioException。

## 易踩坑（⚠️ 已实证）

1. **SDK 直接弹 UI**：client 拦截器与 LyricClient 内直接 `BotToast.showText` / `EasyLoading.show`——SDK 与 UI 耦合，重构 P3 要拆（错误应类型化上抛，由调用方决定提示）。
2. **`search()` 失败静默吞掉**：catch 后返回空 SearchResponse，上层无法区分「无结果」与「请求失败」。
3. **`getBNut()` 每次 `new Dio()`** 且 1 秒内存缓存几乎必失效。
4. **`init()` 整体 try/catch 只 print**：三件套任一失败时 signData 可能为 null → `_signParams` 抛「请先获取签名秘钥」，用户侧表现为搜索永远失败但无提示链路。
5. **取流 URL 是 B 站 CDN 直链**：必须带 `Referer: https://www.bilibili.com/`，否则 403；下载模块 `dio.download` 同样要带（download/model.dart 已带）。
6. **B 站 dash 音频 contentType 按 `video/mp4` 声明**（source.dart 兜底值），实际 m4a；换解析逻辑时注意 just_audio 的 demux 依赖该声明。
7. LyricClient 的 timelessq 代理是**第三方免费服务**，挂了只影响歌词/封面自动补全（silent 模式无提示），别把它当强依赖。

## 易腐字段（改这里时同步更新本文）

- `_cacheVersionValue`（当前 "4"）、`bili_*` 系列 SharedPreferences 键
- mixinKeyEncTab（B 站换表会整体失效）
- playurl 参数（fnval=16）与「bandwidth 最大即最高音质」假设
- LyricClient baseURL `https://api.timelessq.com/music/tencent/`
