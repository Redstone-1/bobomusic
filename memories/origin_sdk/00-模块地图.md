# origin_sdk · 模块地图（v3）

> 接口参数见 `项目文档.md` 第 8 章；本文补**结构**与**易踩坑**。基线：v3 重写（S2 改造 + S5 酷我），2026-10-27 核对。旧 BiliClient 单体已拆分，见 git 历史。

## 一句话模型

`OriginService` 抽象（search/searchSuggest/searchDetail/getMusicUrl/hotSongs）下挂两实现：`BiliApi`（WBI 签名 + BiliAuth 鉴权生命周期，错误类型化）与 `KuwoApi`（免签名第二源）；歌词另立 `LyricService` 三顺位链。全局单例 `biliApi/kuwoApi/lyricService` 可替换（测试模式）。

```
lib/data/origin_service.dart ──声明──> OriginService biliApi = BiliApi() / kuwoApi = KuwoApi()

    ▼

    ├─ Dio 拦截器：非 playurl 请求自动注入 auth.cookieHeader()（playurl 特判不带 cookie，风控继承旧版）
    ├─ code≠0 → BiliApiRejectError（含 v_voucher 风控标记）；DioException 经 _guard 归一
    ├─ getMusicUrl：TtlLruCache 8 条/5min → wbi/playurl fnval=16 → parsePlayUrl（dash 按 bandwidth 取最高 + backupUrl 首项）
    ├─ search/searchSuggest（wbi 签名）/ searchDetail(view)/ searchSeason（UGC 合集 members_archives_list）
    └─ 鉴权三件套在 bili_auth.dart（BiliAuth.ensure 幂等 + _inFlight 并发去重；b_nut → 缓存版本门控 "4"）

    ├─ search：新接口 kuwo.cn/api/v1 → 失败/空回退老接口 r.s（web_2013，parseKuwoJson 兼容单引号 JSON）
    ├─ getMusicUrl：antiserver convert_url3 直取 mp3（MusicUrl.contentType=audio/mpeg，无 backupUrl）
    ├─ hotChart()/themeChart()：广场榜单（见 [[../plaza/00-模块地图]]）
```

## 数据 / 状态链路

- 取流产物 `MusicUrl{url, headers, backupUrl, contentType}` → 上层组装 `PlaySource` 喂引擎（headers 必须带 Referer，B 站缺省 403）。
- 双 OriginType（SDK 枚举带 name="哔哩哔哩"）**按 value 桥接**（`data/mappers.dart` `_mapOrigin`），不能直接混用。
- id 命名空间：`bili:{aid_bvid[_cid]}` / `kuwo:{rid}`（取流时剥前缀）/ `local:{内容指纹}`。

## 易踩坑

- ⚠️ **playurl 请求绝不能带 cookie**（旧版实测风控行为），拦截器特判不能删。
- ⚠️ B 站 -404（"啥都木有"）= 视频/分 P 已失效，状态机层翻译为「原视频可能已丢失」。
- ⚠️ dash 音频 contentType 按 `video/mp4` 声明（demux 依赖），酷我 mp3 为 `audio/mpeg`——见 [[../player/00-模块地图]]。
- ⚠️ 酷我 SSR/老接口文本残留 `\uXXXX` 转义且存在**双重转义**（`\\u0026`），decodeKuwoText 的 `_decodeJsEscapes` 必须允许多道反斜杠，见 [[../bugs/MEM-3-kuwo转义泄漏]]。
- ⚠️ `/rankList/{其它id}` 服务端**忽略 id** 全部返回热歌榜；www bang API 被 csrf 风控——多官方榜暂不可得，勿按候选 id 猜测（实测结论，2026-10-27）。
- ⚠️ 老接口可能返回单引号 JSON，`parseKuwoJson` 有 `_singleQuoteToDouble` 兜底；`searchDetail` 对酷我直接抛不支持。

## 排查清单

| 症状 | 先查 |
| --- | --- |
| 搜索全空但无报错 | 是否误吞错（B 站 search 不再吞错返回空）；酷我回退链是否走到老接口 |
| 取流 403 | headers 是否带 Referer；playurl 是否被误加 cookie |
| 歌手名/封面出现 `\u0026`、`\` | decodeKuwoText/_decodeJsEscapes 是否被绕过（新增文本出口必须过它） |
| 歌词慢 10 倍 | parseLrc 百分秒是否漏 ×10 |
| 鉴权循环失败 | BiliAuth 缓存版本门控值；b_nut 抓取是否被 UA/风控拦截 |

## 易腐字段

`BiliAuth._cacheVersionValue`、TtlLruCache 参数、antiserver 域名与参数名、网易/LRCLIB 端点、`MusicUrl.contentType` 取值。
