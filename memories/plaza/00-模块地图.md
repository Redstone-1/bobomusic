# plaza · 模块地图

> 广场/搜索是 v3 新增 UI 模块；数据源侧见 [[../origin_sdk/00-模块地图]]。2026-10-27 核对。

## 一句话模型

广场 = 搜索入口 + 酷我榜单 TabBar（1 张 SSR 真榜 + 3 张搜索主题卡）；搜索页接 BiliApi/KuwoApi 真搜，**点击先拉详情再分流**（多P/合集进列表，真单曲才播放）。

## 引用关系（谁持有谁）

```
plaza_page.dart        TabBar 四榜（plazaChartDefs）+ TabBarView _ChartListView（keepAlive）
    └─ kuwoChartProvider（hot_songs_provider.dart，family by key，keepAlive）
         ├─ "hot"        → KuwoApi.hotChart()：rankList/16 SSR 解析（三层兜底：SSR rid → 可见标题旧搜索匹配 → 旧搜索）
         └─ "theme:<词>" → KuwoApi.themeChart()：legacy search 30 首（如实命名，不冒充官方榜）
    点行：resolveKuwoHotHit（item 直用 / 标题+歌手搜索 pickKuwoRankItem 匹配，宁缺勿错）
search_page.dart       音源 chip（页内生效默认 B 站）+ 300ms 防抖 + 搜索历史（prefs，置顶/去重/上限 10）
    ├─ 单曲点击 _playWithResolve：searchDetail(view) → orderName 多P / isSeasonDisplay→searchSeason → 合集列表页
    │   （对齐 2.7.0：列表卡片不带合集标记，必须详情分流）；酷我短路直接播
    └─ 合集行 _openCollection/_collectOrder/_showCollectionActions 共用 _fetchCollectionTracks
         （内嵌多P直用 → ugcSeason 走 searchSeason → 其余拉 view）
```

## 易踩坑

- ⚠️ **合集绝不直接播放**：`search_type=video` 卡片不带合集标记，判断 `type==orderName || musicList>1` 只覆盖多P；UGC 合集（is_season_display/ugc_season）type 为 null，必须详情分流（见 [[../bugs/MEM-1-合集误播]]）。
- ⚠️ Tab 切换后 provider 重建需多帧 pump（Tab 动画 + family 重建），widget 测试单帧 pump 会误报未渲染；禁 pumpAndSettle（极光背景）。
- ⚠️ SSR 榜单页解析是字符串级状态机（`_takeArray`），酷我改版最先碎——三层兜底降险，改解析先看 `parseKuwoRankHtml` 测试。

## 排查清单

| 症状 | 先查 |
| --- | --- |
| 点合集/多P报「取流失败」 | 是否绕过 _playWithResolve 直接 toTrack 播放 |
| 榜单卡整排消失 | provider 是否单卡失败被整页吞；各卡 family 独立降级 |
| 热歌榜与主题卡内容相同 | 是否走了 `_searchLegacy("热门歌曲")` 兜底（SSR 页不可用时的降级路径） |

## 易腐字段

`plazaChartDefs` 榜单键、`kuwoChartProvider` family key 约定（"hot"/"theme:<词>"）、rankList 页 class 名（song_name/artist）、`bangList`/`musicList:[` 锚点串。
