# plaza · 模块地图（v3）

> 核对：2026-11-03，源码基线 `073cd0a`。当前五源搜索保留，广场改为网易四榜与千千新歌榜；酷我双榜已下线。本轮核对代码与测试入口，没有重新逐项验证线上榜单可用性。

## 一句话模型

广场按 key 加载独立榜单卡，搜索页按本页选择切换五源；搜索/榜单结果经 mapper 转为 Track，播放和下载按曲目的 origin 继续分发，B 站结果在播放前保留详情分流。

## 入口与引用关系

```text
plaza_page.dart → plazaChartDefs / plazaChartProvider(chartKey)
    └─ hot_songs_provider.dart
         ├─ _apiForChartKey → 五源实例.getChartHits(key)
         ├─ originForChartKey → 榜单所属源
         └─ resolveChartHit → 现成 item / B站补详情 / 酷我无 rid 兜底搜索

search_page.dart
    ├─ _SearchSource / _activeApi → bili / kuwo / netease / qq / qianqian
    ├─ _search → 首屏；_loadMore → 去重追加；_seq → 隔离失效响应
    ├─ _playWithResolve → 非B站直接单曲；B站 searchDetail 后多P/UGC/单曲分流
    ├─ _resolveBiliEntry → 点击与喜欢共用的详情分流（真单曲带 cid / 合集成员）
    └─ _fetchCollectionTracks → 内嵌 musicList / searchSeason / view
         └─ 整包加入队列、整包下载与打开列表复用
```

## 搜索与布局状态链

- 音源仅本页生效，默认 B 站；五个等宽玻璃 chip 排成一行。切源清旧结果并立即重搜当前词，不写全局音源偏好。
- 输入防抖 300ms，但输入变化立即递增 _seq 作废旧请求；切源取消旧防抖。首屏搜索重置页码/结果/hasMore 与翻页加载态，响应先检查 mounted 与序号。
- 列表距底部 400px 预取下一页，按 id 去重追加，并提供“加载更多”以覆盖不足一屏的结果。分页从 resp.current 的最后消费原始页继续；显式 hasMore 优先，否则才按 total/空页推断。
- QQ 每次最多补查三张过滤空页；仍有原始页时空态允许“继续查找”，不误判到底。重复条目仍终止追加；过滤空页且 hasMore=true 允许继续。翻页失败保留已有结果，BiliApiError / QqApiError 展示具体信息，见 [MEM-5](../bugs/MEM-5-QQ音质与分页.md)。
- 搜索成功才记历史；新词置顶、去重、最多 10 条，prefs 持久化。聚焦且无关键词时可展示历史。
- 当前布局为固定头部（返回/输入/音源）+ Expanded 内容区；空态在头部以下的 Stack 中，随可用空间通过 FittedBox 缩放。不要再按早期“全屏空态覆盖”描述实现，键盘和窄屏效果由所有者目检。
- 搜索结果不在搜索阶段整批入库；播放/喜欢等动作才进入持久化链。
- 收藏合集功能已删除（2026-10-30 所有者确认），旧 collection 歌单行由 v4 迁移清除。合集交互（所有者 2026-10-30 定）：点击进列表；喜欢=加载成员后全部歌曲入库喜欢；加入歌单/待播放/下载均按整包处理，加入歌单先取详情列表再逐首加入。

## 榜单、合集与点播

- plazaChartProvider 是按 key 的常驻 FutureProvider.family；每张榜失败独立抛错，UI 对该 key invalidate 重试。
- 当前榜单行读取会话内 vipLimitedTrackIdsProvider 决定灰态和 VIP 标记；集合由播放期酷我时长差探测写入，壳负责提示，并非所有榜单条目预先完成付费判定。见 [播放地图](../player/00-模块地图.md)。
- resolveChartHit 有现成 item 就直接转 Track；B 站缺 cid 的 item 会先补详情。没有 item 时保留为酷我 SSR 旧能力做标题+歌手搜索 → 纯歌名重试 → 最后结果首条回退，不能继续写成“绝不回退近似匹配”。
- B 站搜索卡片不保证含 UGC 标记。单曲行点击先 searchDetail，多 P 和 UGC 合集进入列表，真单曲才播。缺 cid 自愈不是合集识别替代品，见 [MEM-1](../bugs/MEM-1-合集误播.md)。
- 非 B 站源在当前页面按单曲短路，不调用 B 站特有的 view/searchSeason。
- 五榜接口与 SDK 失败/回退语义见 [SDK 地图](../origin_sdk/00-模块地图.md)。

## 易踩坑与排查

| 症状 | 先查 |
| --- | --- |
| 某榜空白/全页受牵连 | 单卡 family key、单卡错误展示、invalidate 的目标 |
| 切源后结果错乱 | _activeApi 捕获、_seq、首屏/翻页中的 mounted 检查 |
| 翻页重复或永远加载 | SDK 最后消费页、显式 hasMore、total、按 id 去重与过滤空页语义 |
| 合集被当单曲处理（播放/只播首 P/误入喜欢） | 是否绕过 _resolveBiliEntry 详情分流 |
| 榜单行可见但点不了 | ChartHit.item、originForChartKey、resolveChartHit |
| 键盘时空态遮头/窄屏溢出 | 固定头部与 Expanded 内容区、FittedBox、chip 留白 |

Tab 动画与异步 family 更新需推进多帧；极光常驻动画下禁用 pumpAndSettle。Fake 数据见 `test/helpers/app_test_helper.dart`，不将 Fake 曲目或一次线上实测写成长效事实。
