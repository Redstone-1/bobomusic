# player · 模块地图（v3）

> 全景见 `项目文档.md`；本文只补**引用关系**与**易踩坑**。基线：v3 重写（S4 播放内核 + 后续收尾），2026-10-27 核对。旧版 2.7.0 的 BBPlayer 三层结构已整体退役，见 git 历史。

## 一句话模型

`Playback`（Riverpod keepAlive 状态机）持有「会话队列 + 播放态」，引擎只做「装载/播放/事件流」，网络曲经 `RangeProxySource` Range 直取 + 边下边播缓存；UI 只面对 `playbackProvider` 单一出口，高频 position 用 `select` 下沉到子组件。

    ├─ 切歌 _jump：QueueRepository().takeFirst()（插队优先）→ nextIndex()（play_mode.dart 纯函数）

## 数据 / 状态链路

- 装载（`_load`）：记旧会话快照 `prev` → `_recordHistory`（upsert + HistoryRepository.record，返回旧时间戳）→ 切 state（buffering）→ 解析源 → engine.load/play → 乐观写 `playing/buffering` → `_persistNow`（含队列快照 `_kQueueIds`）。
- 装载失败：回滚播放历史（`HistoryRepository.restore`）→ **整态回退 `state = prev.copyWith(error:)`**（曲目/队列/进度全回旧曲，引擎旧源未被替换仍在播）。
- 队列持久化：会话队列快照存 prefs（`playback_queue_ids`，与当前曲同刻写入）；插队/稍后听走 queue 表（`[[../db/00-模块地图]]`），`takeFirst` 消费即删。
- 冷启动恢复：track/position/mode + 队列快照回库重建（`TrackRepository.getByIds`，保序、剔除已删曲）；恢复为暂停态。

## 易踩坑

- ⚠️ **播放中显示暂停三角**：引擎已处于播放态时 `play()` 是 no-op、`playingStream` 不再发事件。修复 = 命令侧乐观写 `state.playing`（toggle/systemPlay/_load 三处）。新增播放入口时必须保持这个约定。
- ⚠️ **装载失败不能只挂 error**：`state.track` 已切到新曲，只报错会让 UI 显示没播成的歌。必须整态回退（测试锁定：`playback_provider_test.dart`「整态回退旧曲」）。
- ⚠️ onDispose 禁读 state：dispose 路径写盘用 `_snapshot` 缓存字段（`_snapTrack/_snapPosition/_snapMode/_snapQueue`）。
- ⚠️ `RangeProxySource.cacheDir` 是 static late：main 装配，widget 测试必须先指临时目录，否则 LateInitializationError。
- ⚠️ 测试：FakeEngine 走 `playbackDepsTestOverride`（engine/resolveSource/randomPick 三点注入）；ffi 必须 `databaseFactoryFfiNoIsolate`；TabBarView/常驻动画场景禁 `pumpAndSettle`（极光背景永不停止）。
- ⚠️ `RangeProxySource` 缓存扩展名按音源（`kuwo:` 前缀 .mp3 / 其余 .m4a），`contentType` 随 MusicUrl 透传（B 站 dash=video/mp4，酷我=audio/mpeg）——声明错平台解码器可能拒流。

## 排查清单

| 症状 | 先查 |
| --- | --- |
| 进度/歌词停住不更新 | `_load` 成功分支是否漏清 buffering；position 订阅是否被 buffering 拦截 |
| 播放键状态与实际相反 | 乐观写 playing 是否被新入口绕过；引擎 playingStream 是否不再发事件 |
| 冷启动队列丢失 | `_kQueueIds` 快照写入时机；`getByIds` 是否剔除了未入库曲 |
| 通知栏无响应 | `playbackAudioHandler.commands` 是否已接（仅 Android 非 null） |
| 缓存命中但不播 | `cacheFileFor` 扩展名与实际写入是否一致（.mp3/.m4a） |

## 易腐字段

`playbackProvider` 生成名、`_kTrackId/_kPositionMs/_kMode/_kQueueIds` prefs 键、`PlaybackDeps` 注入面、`MediaControl` 组合、`_MiniProgress/_MiniLyricLine` 子组件名。
