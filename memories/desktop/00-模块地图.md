## 一句话模型与入口

Windows 用独立桌面壳呈现现有业务页面，复用 Repository、Riverpod 和同一个 Playback/AudioEngine；窗口、存储迁移及 SMTC 属于平台边界。

```text
main → prefs → WindowsWindowController → prepareWindowsDatabase → initAppDatabase
     → media_kit / 播放缓存 / SystemMediaCenter → App
App → appPlatformProvider.usesDesktopLayout → DesktopShell
    └─ playerPresentationCoordinatorProvider → 歌词加载 / 最近播放刷新
DesktopShell → desktopNavigationProvider → 内容 Navigator / 已访问页面 IndexedStack
             → DesktopPlayerBar / DesktopNowPlayingPanel / DesktopPlayerPage
             → beforeClose → Playback.prepareForExit → 窗口销毁
Playback ↔ SystemMediaCenter ↔ MethodChannel ↔ C++/WinRT SMTC
```

| 文件 | 职责与约束 |
| --- | --- |
| `lib/core/platform/app_platform.dart` | 只有 Windows 的 `usesDesktopLayout=true`；宽度只决定桌面壳内部布局 |
| `lib/app/desktop/desktop_shell.dart` | 左导航、搜索、嵌套导航、页面保留、播放错误/VIP 提示、快捷键和关闭回调 |
| `lib/core/navigation/desktop_navigation.dart` | 目标页、详情/搜索/播放页的返回栈和选中状态 |
| `lib/core/widgets/desktop_content.dart` | 共用内容视图识别桌面容器，避免套入手机导航和底栏 |
| `lib/features/player/desktop_player.dart` | 常驻底栏、共用播放卡右栏、展开播放页与音量预览 |
| `lib/core/window/windows_window.dart` | 原生标题栏、工作区内恢复窗口、去抖保存与可等待的退出 |
| `lib/data/db/windows_database_path.dart` | 用户支持目录固定库位、唯一旧库快照迁移与校验 |
| `windows/runner/system_media_center.cpp` / `system_media_center.h` | 系统媒体状态、命令、异步封面与平台线程派发 |
| `windows/runner/flutter_window.cpp` | MethodChannel 接入和窗口消息分发 |

## 页面与播放布局

- 左栏宽 212，窗口宽度不超过 820 时用 74 的图标栏；宽度大于 1090 且不是展开播放页时显示 296 的右栏。数值为 Flutter 逻辑像素。
- 按路由及歌单身份保留已访问的内容页，`IndexedStack` 配合 `TickerMode`、`ExcludeFocus` 管理隐藏页。排查重建先检查具体订阅和可见性，不能把保留页面等同于所有隐藏页持续消费高频进度。
- 底栏高 104，通过 `select` 观察必要状态，`PlayerSeekBar` 单独订阅进度；音量拖动先局部预览，松手才提交到 Playback。不要给整个壳订阅完整播放进度。
- 右栏使用 `PlayerCardContent(sidePanel: true)`，复用 App 的歌词、曲目信息及动作行，进度与播放控制交给底栏。手机保留原有播放卡和上下滑切歌入口。
- 展开页左列为歌词工具、可收缩的方形封面及动作，宽度限制在 180～360；没有左列滚动容器、重复“正在播放”标题或歌名歌手块。右侧 `PlayerLyricsView(expanded: true, showTools: false)` 撑满内容高度，底栏仍显示歌曲信息。
- 展开/收起只有底栏最右端固定入口（`desktop_player_expand`）。封面下动作按 48 的槽位计算容量并 `spaceEvenly` 均匀分布，只有放不下的动作进入更多，同时预留更多按钮本身的槽位。
- 桌面封面读取 `Track.effectiveCover`；详情、目录、队列与当前会话刷新关系见 [数据地图](../db/00-模块地图.md)。歌词居中算法见 [播放地图](../player/00-模块地图.md)。
- 快捷键：Space 播放/暂停、Alt+左右切歌、F 展开/收起、Q 队列、Esc 返回、Ctrl+K 搜索；编辑框、菜单和弹层焦点需要一起回归。

## 启动、存储和关闭

- 启动先初始化桌面 FFI 工厂、prefs 和 Windows 窗口，再准备数据库；失败显示 `lib/app/startup_failure_app.dart` 错误/重试页，不静默创建空库掩盖错误。
- 数据库固定到应用支持目录的 `databases/bobomusic3.db`。迁移检测有限的旧 FFI/工作目录/程序目录候选；唯一候选用只读连接 `VACUUM INTO ?` 生成含 WAL 已提交数据的快照，`quick_check` 和必要表校验通过后转正。多候选或坏库明确报错，保留原库；已有目标库直接使用，不覆盖。
- `windows/runner/Runner.rc` 的 CompanyName/ProductName 会影响 path_provider 的用户目录，不能仅为品牌展示随意修改。Debug/Release 当前共享这套用户数据位置，没有 Android 的包名隔离。
- 初始窗口 1440×900、最小 800×600；恢复时限制到可用显示器工作区，位置/尺寸/最大化状态按 300ms 去抖保存。断开外屏和系统缩放需实际验收。
- 关闭窗口先保存窗口状态，再等待 `prepareForExit` 排空 seek/音量/倍速操作、暂停和写入会话快照；保存失败提示并保留窗口。最小化继续播放，未接托盘。

## Windows 系统媒体桥

- Dart `lib/features/player/system_media_center.dart` 使用 `com.bobomusic/media_center`，把系统命令交回同一个 Playback，普通时间轴同步按秒节流。标题、歌手、有效封面、状态、进度和倍速来自当前快照；不启动第二个播放器。
- C++/WinRT 的系统事件与文件异步完成可能不在 Flutter 平台线程；先入队并 `PostMessage(WM_APP + 0x51)`，由 FlutterWindow 消息处理后调用通道。不要从任意回调线程直接 `InvokeMethod`。
- 封面读取只在异步操作完成后取结果；弱引用、存活状态和封面代次防止退出后访问及旧封面覆盖新曲。销毁时撤销事件订阅并清除会话。
- SMTC 是否展示 seek/倍速入口由系统界面决定；单元测试验证协议不等于媒体键、睡眠唤醒或系统面板已验收。

## 工具链、图标与分发

- `.vscode/launch.json` 提供固定设备的 Windows Debug 配置；Visual Studio 需安装 C++ 桌面工作负载。`windows/CMakeLists.txt` 只移除 permission_handler_windows 的旧 `/await`；runner 使用 C++20。已核实的编译错误与安装拒访见 [MEM-7](../bugs/MEM-7-Windows工具链与安装权限.md)。
- `assets/icon/desktop.png` 为独立圆角透明素材，复制自 `assets/readme-logo.png`；`flutter_launcher_icons.yaml` 的 Windows/macOS 使用该源。Windows 原生资源为 `windows/runner/resources/app_icon.ico`；改图标后要停止并重启，热重载不生效。
- `.github/workflows/release-windows.yaml` 支持手动选分支产出 Artifact，以及版本匹配的 `v*` 标签发布；内置锁文件/analyze/test 门禁、Release 构建、x64 CRT 收集和校验和。手动运行不创建 Release，当前未配置 Windows 签名。
- `windows/package.ps1` 只归档已有完整 Release；`windows/installer.iss` 使用固定 AppId、管理员安装权限、Program Files 默认目录和 `runasoriginaluser` 自动启动，中文资源在 `windows/installer/`。安装目录和用户数据目录分离，不配置用户数据卸载删除。
- 操作步骤及待验收清单统一在 [发布与验收](../../windows/发布与验收.md)，批次记录在 [开发计划](../../windows开发计划.md)。不据本机一次编译或安装声明完成全平台适配。
