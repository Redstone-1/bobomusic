# download · 模块地图（v3）

> 核对：2026-11-03，源码基线 `073cd0a`，依据实现与 `test/download/` 的替身/本地 HTTP 场景。真实五源下载、权限、断网播放与文件管理器交互仍需所有者按平台验收。

## 状态与文件链

```text
download_actions / downloads_page → DownloadTasks（keepAlive，会话任务）
    → DownloadService → 已登记本地文件 / 完整播放缓存 / 按 origin 取流
        → DownloadTransfer → .part + .part.json → 完整目标文件
        → TrackRepository.markDownloaded → downloadedTracksProvider → 已下载列表
```

| 文件 | 职责 |
| --- | --- |
| `lib/features/download/download_tasks.dart` | 按曲目 ID 管理 run/token/done，暂停、继续、取消、重试和迟到结果保护 |
| `lib/features/download/download_service.dart` | 权限、平台目录、缓存复用、五源分发、临时文件转正和数据库登记 |
| `lib/features/download/download_transfer.dart` | HTTP 流、强校验续传、范围/长度校验和句柄释放 |
| `lib/features/download/download_actions.dart` / `downloads_page.dart` | 操作入口、任务/已下载列表与打开所在目录 |
| `lib/features/player/range_proxy_source.dart` | 完整播放缓存入口，供下载复制复用，不是任务状态的持有者 |

## 关键约束

- 任务状态为 queued/downloading/paused/completed/failed；列表与任务在内存，已下载事实由数据库和正式文件持有。不能把 `.part` 存在或 UI 进度到达 1 当作已下载。
- 同曲只能一个 run 持有写入权；继续/重试等待旧 run 的 done，不能边释放句柄边重新写同一路径。进度回调同时核对 provider 存活、token 和当前 run 身份，避免取消后任务复活。
- 暂停用 `CancelToken("pause")` 中断实际传输，保留 `.part` 和校验信息；取消用 `"cancel"`，等待旧传输结束后清理。取消后的清理期间仍占用 run，防止新传输被旧清理删掉。离开下载页不销毁 keepAlive 任务。
- 续传要求 `.part.json` 中有强 ETag 或 Last-Modified、已知总长以及有效部分文件。请求带 Range/If-Range 和 identity 编码；不能因签名 URL 看似相同就盲目拼接。
- 206 校验起点、末点、总长和 Content-Length；校验标记或总长变化从零重取，200 忽略 Range 时截断重写，不把完整响应追加到旧部分文件。空文件或已知总长不匹配均失败。
- 传输成功、流和文件句柄关闭后，Service 才 rename 转正并 `markDownloaded`。取消/失败回滚本次登记和本次创建的目标；只有暂停保留临时文件。Dio 流异常也需取消底层连接。
- 文件名保留原始歌名/歌手，并附曲目 ID 的 MD5 摘要隔离同名歌曲；不能按显示名合并身份。编辑显示信息不会重命名下载文件；旧下载优先从库内 localPath 找回。
- 下载后的在线曲仍保留原 origin/id，播放器先检查本地路径；失效在线路径才回原源，本地曲缺文件报错。见 [播放地图](../player/00-模块地图.md) 和 [数据地图](../db/00-模块地图.md)。
- Windows 下载位于系统 Downloads 下的 `啵啵音乐/`（不可用时退到文档目录），与应用音频缓存和导入副本分开；移除下载记录、取消任务与清空缓存是不同动作。

## 排查与验证

| 现象 | 先查 |
| --- | --- |
| 取消后任务又出现 / 继续后文件消失 | `_runs` 身份、token、done 等待和旧 run 清理 |
| 续传文件重复或无法解码 | Range 206 校验、200 截断、validator/total 是否匹配 |
| UI 显示已下载但离线失败 | 正式文件、localPath、markDownloaded 时机，不能读 `.part` |
| 同名曲互相覆盖 | `downloadFileName` 的 ID 摘要，不按标题拼唯一键 |
| 播放缓存存在却重复取流 | `RangeProxySource.cacheFileFor` 与最高音质缓存版本 |

回归入口：`test/download/download_tasks_test.dart`、`test/download/download_transfer_test.dart`、`test/download/download_service_test.dart`。修改协议后同时核对下载路径与播放缓存路径；本地 HTTP 测试不能保证每个线上 CDN 支持续传。
